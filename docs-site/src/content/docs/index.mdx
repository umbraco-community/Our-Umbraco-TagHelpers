## Install in two steps

Add the package to your Umbraco website project:

```bash
dotnet add package Our.Umbraco.TagHelpers
```

Then register the tag helpers at the bottom of `Views/_ViewImports.cshtml`:

```cshtml
@addTagHelper *, Our.Umbraco.TagHelpers
```

## Before and after

Tag helpers turn Razor logic into attributes and elements. This link only renders when the content picker has a value, and so does the image inside it:

```cshtml title="Before"
@if (Model.ContentPickerThing != null)
{
    <a href="@Model.ContentPickerThing.Url()" class="btn">
        <span>@Model.ContentPickerThing.Name</span>
        @if (Model.LinkMediaPicker != null)
        {
            <img src="@Model.LinkMediaPicker.Url()" />
        }
    </a>
}
```

```cshtml title="After"
<a our-if="Model.ContentPickerThing != null" href="@Model.ContentPickerThing?.Url()" class="btn">
    <span>@Model.ContentPickerThing?.Name</span>
    <img our-if="Model.LinkMediaPicker != null" src="@Model.LinkMediaPicker?.Url()" />
</a>
```
